# Finance Transaction Analysis Dashboard (Excel)

This project is an advanced Excel-based Finance Transaction Analysis Dashboard built using a dataset of 100,000+ transaction records. The project demonstrates end-to-end data analysis skills, including data cleaning, data transformation, Pivot Tables, KPI reporting, advanced Excel formulas, conditional formatting, data visualization, and interactive dashboard design.

## Project Features
- Data cleaning and preparation of 100,000+ records
- KPI calculation and performance tracking
- Pivot Table analysis for transaction insights
- City-wise transaction amount analysis
- Payment method usage analysis
- Account type comparison
- Monthly transaction trend analysis
- Risk score categorization and conditional formatting
- Interactive dashboard with charts, slicers, and timeline filters
- Professional dashboard layout for business reporting

## Excel Skills Used
- Pivot Tables
- Pivot Charts
- IF & Nested IF Functions
- VLOOKUP / INDEX-MATCH
- Conditional Formatting
- Slicers & Timeline
- KPI Cards
- Data Visualization
- Dashboard Design

## Dashboard Insights
The dashboard provides a comprehensive view of transaction performance, customer behavior, payment preferences, account distribution, risk analysis, and monthly transaction trends, helping users make data-driven financial decisions.

## Files Included
- RAW_DATA – Source transaction dataset
- KPI – Key Performance Indicators
- PIVOT – Analytical Pivot Tables
- DASHBOARD – Interactive Excel Dashboard
